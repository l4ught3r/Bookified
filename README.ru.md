## ✨ Введение

Bookified — платформа на базе искусственного интеллекта, позволяющая вести голосовые диалоги с вашими книгами в режиме реального времени. Построена на Next.js 16, Vapi и MongoDB. Платформа превращает PDF-файлы в интерактивные сущности с помощью естественного голосового синтеза. Выбирайте персонажей ElevenLabs, общайтесь со своей библиотекой, запрашивайте резюме и просматривайте транскрипции диалогов — всё это в стильном интерфейсе Shadcn UI с аутентификацией через Clerk.

## ⚙️ Технологический стек

- **[Clerk](https://clerk.com/)** — комплексная платформа управления пользователями и аутентификации. Предоставляет готовые защищённые компоненты для входа через email и социальные сети, обеспечивая удобное управление сессиями и защищённые маршруты с минимальной настройкой.

- **[CodeRabbit](https://app.coderabbit.ai/)** — платформа проверки кода на основе ИИ, обеспечивающая контекстный построчный анализ pull request'ов. Автоматизирует процесс проверки: выявляет ошибки, предлагает оптимизации и следит за соблюдением стандартов кода, существенно снижая нагрузку на разработчиков и повышая качество кода.

- **[ElevenLabs](https://elevenlabs.io/docs)** — продвинутая ИИ-платформа для синтеза речи, звучащей как живой человек. Отвечает за предварительное прослушивание голосов в Bookified, позволяя пользователям выбрать подходящего ИИ-персонажа перед началом разговора.

- **[MongoDB](https://www.mongodb.com/docs/)** — гибкая документно-ориентированная NoSQL база данных, разработанная для масштабируемости и удобства разработчиков. В связке с Mongoose служит основным хранилищем пользовательских библиотек, метаданных книг и транскрипций диалогов.

- **[Next.js](https://nextjs.org/docs)** — мощный React-фреймворк для создания полнофункциональных веб-приложений. Отвечает за основную логику приложения, серверный рендеринг и API-маршруты, обеспечивая быстрый и отзывчивый интерфейс платформы Bookified.

- **[Shadcn UI](https://ui.shadcn.com/)** — коллекция переиспользуемых доступных компонентов на Tailwind CSS и Radix UI. Позволяет создать чистый, модульный и профессиональный пользовательский интерфейс, который легко настраивать и темизировать.

- **[TypeScript](https://www.typescriptlang.org/)** — надмножество JavaScript со статической типизацией, обеспечивающее лучшие инструменты разработки, качество кода и раннее обнаружение ошибок. Гарантирует поддерживаемость и надёжность приложения по мере роста кодовой базы.

- **[Vapi](https://vapi.ai/)** — специализированная платформа голосового ИИ для разговоров в реальном времени с минимальной задержкой. Является основным движком Bookified, позволяя пользователям вести полноценные голосовые диалоги с загруженным контентом.

- **[next-intl](https://next-intl.dev/)** — библиотека интернационализации для Next.js, обеспечивающая бесшовную мультиязычную поддержку с локализованной маршрутизацией, переводами и форматированием. Обеспечивает работу системы локализации Bookified, создавая комфортный опыт для пользователей из разных стран.

## 🔋 Возможности

👉 **Загрузка и обработка PDF**: Загружайте PDF-книги с автоматическим извлечением текста, интеллектуальным разбиением на части и построением высокоразмерных эмбеддингов для точного извлечения контекста.

👉 **Голосовые диалоги**: Ведите естественные голосовые разговоры с загруженными книгами в реальном времени — задавайте вопросы и исследуйте сложные концепции устно через Vapi.

👉 **Голосовые персонажи ИИ**: Выбирайте из множества уникальных ИИ-персонажей и слушайте мгновенные предварительные прослушивания высокой чёткости на базе ElevenLabs, чтобы найти идеального компаньона для чтения.

👉 **Умные резюме и аналитика**: Быстро извлекайте суть любой главы или запрашивайте глубокие резюме, делая объёмный контент более доступным и понятным.

👉 **Транскрипции сессий**: Сохраняйте полную запись каждого голосового взаимодействия с автоматически генерируемыми текстовыми транскрипциями — ни одна важная мысль из обсуждения не будет потеряна.

👉 **Управление библиотекой**: Легко организуйте и выполняйте поиск по личным загрузкам или общей коллекции с помощью высокопроизводительного поискового интерфейса.

👉 **Авторизация и подписки**: Безопасный доступ пользователей через email и социальные сети в сочетании с надёжной системой оплаты для управления премиум-функциями и подписками на платформу.

И многое другое, включая архитектуру кода и переиспользование компонентов.

## 🤸 Быстрый старт

Следуйте этим шагам, чтобы запустить проект локально на вашем компьютере.

**Требования**

Убедитесь, что на вашем компьютере установлено следующее:

- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/en)
- [npm](https://www.npmjs.com/) (менеджер пакетов Node)

**Клонирование репозитория**

```bash
git clone https://github.com/l4ught3r/Bookified
cd bookified
```

**Установка зависимостей**

Установите зависимости проекта с помощью npm:

```bash
npm install
```

**Настройка переменных окружения**

Создайте новый файл .env в корне проекта и добавьте следующее содержимое:

```env
NODE_ENV='development'
NEXT_PUBLIC_BASE_URL=

# CLERK
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=
CLERK_SECRET_KEY=
NEXT_PUBLIC_CLERK_SIGN_IN_URL=/sign-in
NEXT_PUBLIC_CLERK_SIGN_UP_URL=/sign-up
NEXT_PUBLIC_CLERK_SIGN_IN_FALLBACK_REDIRECT_URL=/
NEXT_PUBLIC_CLERK_SIGN_UP_FALLBACK_REDIRECT_URL=/

# VERCEL BLOB
BLOB_READ_WRITE_TOKEN=

# MONGODB
MONGODB_URI=

# VAPI
NEXT_PUBLIC_VAPI_API_KEY=
VAPI_SERVER_SECRET=

# Google Gemini API for embeddings
GOOGLE_GEMINI_API_KEY=

# ELEVENLABS
ELEVENLABS_API_KEY=
```

Замените значения-заполнители реальными учётными данными. Их можно получить, зарегистрировавшись на: [**Clerk**](https://clerk.com), [**Vercel**](https://vercel.com), [**MongoDB**](https://www.mongodb.com), [**Vapi**](https://vapi.ai), [**Google AI Studio**](https://aistudio.google.com), [**ElevenLabs**](https://elevenlabs.io).

**Запуск проекта**

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере для просмотра проекта.
